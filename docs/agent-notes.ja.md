# Agent Notes

- `src/jsx-runtime.ts` の `h()` を更新し、`createElement` を呼び出す前に `flat` 配列に1レベル手動でフラット化することで `children.flat()` の使用を回避しました。
- Vitrio、Solid、React のベンチマークビルドを実行し、`results.md` と `docs/benchmarks.md` のベンチマーク概要数値を更新しました。
- ベンチマークの記述を明確化し、どの指標がリードしており、どれがまだ遅れているかを反映しました。
- `<For>` の更新パスを最適化し、ベンチマークハーネス/ロードのタイミングを調整してから、ベンチマークを再実行しました。
- README のパフォーマンステーブルとコピーを `results.md` を反映するように更新し、英語/日本語セクションとライセンス年を調整しました。
- `signal.rs` における `propagate` WASM 関数を最適化しました。スタックに割り当てられた配列のゼロ初期化という高コストな処理から、静的で変更可能なグローバル配列 (`QUEUE` と `VISITED_WORDS`) へと切り替えました。これにより、WASM 移植に伴う速度の低下が改善され、`memset` のボトルネックが回避されました。
